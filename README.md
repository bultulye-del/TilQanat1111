# TilQanat — сайтты орналастыру (5 минут)

Бұл папкада дайын сайт бар. Орнату, npm немесе бағдарламалау КЕРЕК ЕМЕС.

## 1. Сайтты интернетке шығару (Netlify Drop)
1. zip-файлды компьютерге ашып (Extract), `tilqanat-site` папкасын алыңыз.
2. https://app.netlify.com/drop сілтемесін ашыңыз (тегін аккаунт ашу сұралуы мүмкін).
3. `tilqanat-site` папкасын сол беттегі аймаққа сүйреп апарыңыз.
4. Бірнеше секундтан соң сайт мекенжайы шығады, мысалы `https://xxxx.netlify.app`. Оны көшіріп алыңыз.

## 2. Supabase-ке мекенжайды енгізу
Supabase дашбордында: Authentication → URL Configuration:
- Site URL = сіздің netlify мекенжайыңыз
- Redirect URLs-ке де сол мекенжайды қосыңыз (соңына `/**` қосыңыз)

Сынақ кезінде Authentication → Providers → Email бөлімінде «Confirm email» өшіріп қойсаңыз, тіркелу жылдамырақ болады. Нақты қолданушыларға ашар алдында қайта қосыңыз.

## 3. Тексеру
- Сайтта тіркеліңіз (5 жасқа сәйкес туған күн + ата-ана келісімі).
- Деңгейлер → 1-деңгей → Hello! → сабақ → тест.
- Colours тақырыбы Hello! тестінен өткен соң ашылуы керек.

## 4. Әкімші
Сайтта тіркелген соң email-іңізді чатқа жазыңыз — әкімші құқығы беріледі.

## Файлдар
- index.html — бет
- style.css — дизайн
- app.js — барлық логика (тіркелу, сабақ, тест, кабинет, әкімші)
- config.js — Supabase мекенжайы мен публичный кілті
